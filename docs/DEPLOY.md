# Развёртывание Dizzit AI

Документ описывает **временную бесплатную схему** — как проект выложен сейчас,
чтобы показывать его людям до продакшена. Здесь же — что менять при переходе
на целевую схему (Railway + база + хранилище) и что откатывать.

Родственные документы: [`PLATFORM_ARCHITECTURE.md`](PLATFORM_ARCHITECTURE.md) —
целевая серверная архитектура (провайдеры ИИ, очередь, квоты);
[`UPSOUND_INFRA_REPLICATION.md`](UPSOUND_INFRA_REPLICATION.md) — как развёрнута
инфраструктура UpSound в Railway и Supabase.

| Стоимость | **$0/мес** |

Дата развёртывания: 4 сентября 2026.

### Почему этого достаточно

Приложение целиком клиентское: состояние живёт в браузере пользователя —
метаданные в `localStorage` (zustand + persist), изображения в IndexedDB
(`src/lib/blob-store.ts`). Сервера у проекта нет, ключей провайдеров нет,
все три инструмента работают на локальных движках-предпросмотрах
(`enhance-engine.ts`, `model-engine.ts`, `material-engine.ts`).

Сборка полностью статическая — все восемь маршрутов пререндерятся
(`○ (Static)` в выводе `next build`). Для такой сборки Vercel Hobby —
ровно то, что нужно: CDN, HTTPS, домен, автодеплой.

### Чего сейчас НЕТ и почему это правильно

| Сервис | Зачем нужен | Почему пока не подключён |
| --- | --- | --- |
| База данных (Neon / Supabase) | Задачи, пользователи, учёт расходов | Нечего хранить: источник правды — браузер |
| Объектное хранилище (R2 / S3) | GLB-модели, рендеры, загрузки | Файлы лежат в IndexedDB у пользователя |
| Redis (Upstash) | Очередь задач, лимитеры | Очереди нет, воркера нет |
| Railway | Воркер, длинные процессы | Долгих процессов нет — все страницы статические |
| Ключ Meshy | Генерация 3D из фото | **API Meshy требует платного тарифа** — на free плане ключ не создаётся |

## 2. Что было изменено в проекте

Изменения минимальные — код приложения не тронут вообще.

### 2.1 Инициализирован git

Проекта раньше не было под контролем версий. Создан репозиторий,
первый коммит `c4e98c3` содержит всё состояние на момент развёртывания.

```bash
git init
git remote add origin https://github.com/ashseryoja/dizzit-ai.git
```

### 2.2 Дополнен `.gitignore`

Добавлены две строки — каталог превью-сборки и служебный каталог Vercel:

```diff
 node_modules
 .next
+.next-preview
 out
 build
 .DS_Store
 *.pem
+
+# vercel
+.vercel
```

`.next-preview` — каталог, в который собирается конфигурация `dizzit-ai-auto`
из `.claude/launch.json` (см. `next.config.js`, переменная `NEXT_DIST_DIR`).

### 2.3 Создан проект на Vercel

Импортом репозитория с GitHub. Настройки — по умолчанию, framework
определился как Next.js автоматически. **Переменных окружения нет ни одной.**

### Что НЕ менялось

- Ни одного файла в `src/`.
- `package.json`, `next.config.js`, `tsconfig.json` — без изменений.
- Никаких зависимостей от Vercel в коде: ни `@vercel/*` пакетов, ни
  Vercel Postgres / Blob / KV. Проект остаётся обычным Next.js-приложением,
  которое собирается и запускается где угодно.

## 3. Переход в продакшен

Порядок — от простого к сложному. Каждый шаг самостоятелен, «наполовину»
не оставлять.

### Шаг 1. Оплатить Meshy и подключить 3D

1. Оформить тариф **Meshy Pro ($20/мес, 1000 кредитов)** — без него API
   недоступен: в кабинете висит «Please upgrade to a premium plan to create
   API tasks».
2. Settings → API → **Create API Key** (показывается один раз).
3. Ключ положить в `.env.local` локально и в **Environment Variables**
   проекта на Vercel — переменная `MESHY_API_KEY`, **без префикса
   `NEXT_PUBLIC_`** (иначе ключ уедет в браузерный бандл).
4. Появляется первый серверный роут — тонкий прокси, прячущий ключ.
   С этого момента сборка перестаёт быть полностью статической.

Себестоимость генерации: **~$0.60** за модель с текстурой (30 кредитов).

### Шаг 2. База данных

Нужна, когда появятся настоящие пользователи: аккаунты, история задач,
учёт потраченных кредитов, продолжение задачи после закрытия вкладки
(вебхук Meshy без базы бесполезен — некуда записать результат).

- Временно: **Neon** (free tier) — обычный Postgres.
- Целевое: **Supabase** (по решению в `UPSOUND_INFRA_REPLICATION.md`).
- Переезд между ними — `pg_dump` + смена `DATABASE_URL`, **при условии**
  что работа с базой идёт через обычный драйвер/ORM (Drizzle, Prisma),
  а не через фирменный клиент `supabase-js`.

### Шаг 3. Объектное хранилище

Нужно, когда GLB-модели и рендеры перестанут помещаться в браузер и
понадобятся между устройствами.

**Cloudflare R2** — 10 ГБ бесплатно и, что важнее, **нет платы за
исходящий трафик**: 3D-модели тяжёлые, и на S3 трафик стал бы главной
статьёй счёта. R2 не требует переезда при смене хостинга — работает
одинаково откуда угодно, поэтому его можно завести сразу и навсегда.

Важно: ссылки Meshy на результат **истекают** (`expires_at`), поэтому
GLB надо скачивать к себе сразу по готовности задачи.

### Шаг 4. Railway, воркер и очередь

Момент перехода наступает, когда выполняется любое из условий:

- начали брать деньги с пользователей → **тариф Vercel Hobby запрещает
  коммерческое использование**, нужен Vercel Pro ($20/мес) или переезд;
- нужен фоновый воркер: пакетная обработка, повторные попытки, разбор
  зависших задач — на Vercel долгих процессов нет;
- нужны приоритеты в очереди и контроль параллельных вызовов провайдера.

Переезд приложения: собрать Docker-образ (в архитектуре уже заложен
«один образ, роль процесса — `PROCESS_ROLE`»), перенести переменные
окружения, переключить домен. База и R2 остаются на месте — переносится
только приложение.

Очередь: `InlineQueue` → `BullMqQueue`. По архитектуре это правка
**одного файла** `server/container.ts`, а не переписывание use case'ов —
при условии, что вызовы провайдеров с самого начала спрятаны за портом
`JobQueue`, а не разбросаны по роутам.

## 4. Откат

Если бесплатную схему нужно убрать целиком, отката как такового не
требуется — код приложения не менялся. Достаточно:

1. **Vercel** — удалить проект: Settings → Advanced → Delete Project.
   Домен `dizzit-ai.vercel.app` освободится.
2. **GitHub** — удалить репозиторий `ashseryoja/dizzit-ai`, если код
   должен остаться только локально. *Осторожно: это единственная копия
   истории проекта — до удаления убедиться, что рабочая папка на месте.*
3. **`.gitignore`** — вернуть две строки (`.next-preview`, `.vercel`),
   если они мешают. Практического смысла в этом нет.
4. **Neon / Cloudflare** — если аккаунты были заведены, но не
   использованы, их можно просто оставить: бесплатные тарифы ничего
   не стоят и не требуют карты.

Локальная разработка от развёртывания не зависит: `npm run dev` работает
как раньше, ничего подключать не нужно.

## 5. Ограничения текущей схемы — что говорить тестировщикам

- **Данные живут в браузере.** Другой браузер или устройство — пустой
  проект. Очистка данных сайта стирает всё безвозвратно.
- **Резервная копия** — только через экспорт JSON в настройках, и он
  **не включает изображения** (они в IndexedDB).
- **Генерации ненастоящие.** Все три инструмента — локальные
  предпросмотры, показывающие интерфейс и логику, а не работу ИИ.
  Первым настоящим станет «Фото → 3D» после шага 1.
- **Тариф Hobby — некоммерческий.** Показывать людям можно, брать
  деньги — нет.
